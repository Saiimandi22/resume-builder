STEP 6: ADD TO YOUR PROJECT

Go to your project folder and open the .env file:

Your .env file should look like:

┌──────────────────────────────────────────┐
│ ANTHROPIC_API_KEY=your_anthropic_key    │
│ GOOGLE_API_KEY=your_google_key_here     │
│ LLM_PROVIDER=claude                      │
│ PORT=5000                                │
│ NODE_ENV=development                     │
└──────────────────────────────────────────┘

CHANGE IT TO:

┌──────────────────────────────────────────┐
│ ANTHROPIC_API_KEY=your_anthropic_key    │
│ GOOGLE_API_KEY=AIzaSyD_xxx... (paste)   │👈 Paste your key here
│ LLM_PROVIDER=google                      │👈 Change to 'google'
│ PORT=5000                                │
│ NODE_ENV=development                     │
└──────────────────────────────────────────┘

Replace "AIzaSyD_xxx..." with your ACTUAL key (the one you copied!)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 7: SAVE AND RESTART
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Save your .env file
   - If using nano: Press Ctrl+O, then Enter, then Ctrl+X
   - If using VS Code: Press Ctrl+S

2. Stop the server if it's running
   - Press Ctrl+C

3. Restart the server
   - Type: npm run dev
   - You should see: "LLM Provider: google" ✅

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Cannot find GOOGLE_API_KEY"
Solution: 
  1. Make sure .env file exists in your project root
  2. Make sure you pasted the ENTIRE key
  3. Restart the server

Problem: "API key is invalid"
Solution:
  1. Get a new key from https://aistudio.google.com/app/apikey
  2. Make sure you copied it correctly
  3. No extra spaces before or after

Problem: "API quota exceeded"
Solution:
  1. Google free tier: 15 requests per minute
  2. Wait 1 minute and try again
  3. Or upgrade to paid plan

Problem: "GenAI is not defined"
Solution:
  1. Run: npm install @google/generative-ai
  2. Restart the server
