# 🚀 QUICK REFERENCE - Google API Key Setup

## **In 60 Seconds:**

### 1️⃣ Get Your Key (2 minutes)
```
👉 Go to: https://aistudio.google.com/app/apikey
👉 Sign in with Google
👉 Click "Create API Key"
👉 Click "Copy" on your key
```

### 2️⃣ Add to Project (1 minute)
```bash
# Edit your .env file and add:
GOOGLE_API_KEY=AIzaSyD_...paste-your-key-here...
LLM_PROVIDER=google
```

### 3️⃣ Restart Server (1 minute)
```bash
# Stop server (Ctrl+C if running)
npm run dev
# See: "LLM Provider: google" ✅
```

### 4️⃣ Use It! (1 minute)
```
Open: http://localhost:3000
Enter resume → Paste job → Click "Fine-tune"
Done! 🎉
```

---

## 📋 Your Key Looks Like This:
```
AIzaSyD_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
↑
Starts with "AIzaSyD_"
Looks like a long random string
```

---

## ✅ Your .env File Should Be:
```env
GOOGLE_API_KEY=AIzaSyD_...your-actual-key...
LLM_PROVIDER=google
PORT=5000
NODE_ENV=development
```
